# Códigos Auxiliares

![Python](https://img.shields.io/badge/Python-3-blue)

Scripts em Python usados para conferir as resoluções da primeira lista de exercícios da disciplina, validando se cada etapa e o resultado final batiam com o esperado.

---

## Arquivos

| Arquivo | Descrição |
|---|---|
| `bissecao.py` | Método da bisseção |
| `falsa_posicao.py` | Método da falsa posição (regula falsi) |
| `newton.py` | Método de Newton |
| `pontofixo.py` | Método do ponto fixo |
| `secante.py` | Método da secante |

Não são um projeto formal, apenas scripts avulsos.

---

## Como rodar

```bash
python3 nome_do_arquivo.py
```
