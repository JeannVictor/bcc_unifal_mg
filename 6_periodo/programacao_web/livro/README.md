# Livro de Programação Web

Reconstrução editorial do livro autoral de Programação Web.

- `original/`: PDF original preservado.
- `latex/`: fonte LaTeX editável, dividida em 34 capítulos.
- `markdown/`: versão textual em Markdown.
- `livro_programacao_web.pdf`: versão recompilada e verificada.

A reconstrução foi feita a partir do texto e da estrutura do PDF, pois o arquivo `.tex` original não estava embutido.
